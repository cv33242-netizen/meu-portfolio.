## 🏥 Projeto em Destaque — SmartBed

### Sistema Inteligente de Monitoramento de Leitos

O **SmartBed** nasceu como um projeto acadêmico com o objetivo de aplicar conhecimentos de Desenvolvimento de Sistemas, Internet das Coisas e Sistemas Embarcados na solução de um problema real.

O sistema foi projetado para monitorar a ocupação e a disponibilidade de leitos, enviando as informações coletadas por sensores para um dashboard centralizado.

### Tecnologias do Projeto

- ESP32
- Sensores de pressão
- Wi-Fi
- MQTT
- Mosquitto
- Node.js
- API REST
- Lovable

### ⚙️ Como Funciona

O funcionamento do sistema segue o fluxo:

**Sensor → ESP32 → Wi-Fi → API → Dashboard**

O sensor identifica alterações de pressão, o ESP32 processa as leituras e transmite as informações para a aplicação responsável pelo monitoramento.

### 📊 Características do Sistema

- **27 leitos planejados** para monitoramento
- Monitoramento conectado por IoT
- Projeto de operação contínua
- Atualização dos estados de ocupação
- Identificação de leitos disponíveis, ocupados e offline

### 🔄 Evolução do Projeto

**01 — Sensoriamento**

Desenvolvimento das primeiras leituras utilizando sensores conectados ao ESP32.

**02 — Comunicação MQTT**

Integração utilizando ESP32, Wi-Fi, MQTT, Mosquitto e Node.js.

**03 — Dashboard**

Criação de uma interface centralizada para visualizar os estados dos leitos.

**04 — API e Lovable**

Evolução para comunicação entre ESP32, API e aplicação web.

**05 — Testes e Melhorias**

Calibração dos sensores, testes de comunicação, análise de desempenho e aprimoramento da interface.
