Bem-vindo ao meu portfólio!  
Este repositório contém o código-fonte da minha **Home Page Profissional e Pessoal**, desenvolvida para apresentar minha trajetória como **Analista de TI**, **Desenvolvedor Java Full Stack** e **Professor Universitário**.

## 📌 Sobre Mim

Atuo como **Analista de TI na AADESAM**, pelo **Projeto Novo TJAM**, trabalhando com suporte, sustentação, testes, homologação e integração de sistemas do Poder Judiciário do Amazonas, como:

- PROJUDI  
- PJeCor  
- Correições  
- Certidões  
- Custas  

Realizo integrações via **API REST** com os Correios (AR Digital) e via **SOAP/MNI** com o Ministério Público.  
No cotidiano, executo:

- Consultas e manutenções em **PostgreSQL** via DBeaver  
- Análise de logs em servidores  
- Gestão de chamados no **JIRA**  
- Mediação entre áreas de negócio e desenvolvimento, traduzindo necessidades em requisitos técnicos claros  

Também possuo experiência consolidada como **Desenvolvedor Java Full Stack**, utilizando:

- **Spring Boot**, Hibernate, JPA, Maven  
- **Tomcat**, JUnit, Mockito  
- **Git**, APIs REST documentadas em Swagger  
- **Angular** e **TypeScript**  
- Bancos relacionais (**PostgreSQL**, **Oracle**) e NoSQL  

Atuei em projetos dos setores **Judiciário, Bancário, Governamental, Industrial e Educacional**, com foco em evolução de sistemas legados, refatoração, Clean Code e TDD em ambientes ágeis (Scrum e Kanban).
